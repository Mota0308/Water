# 01 — 手機殼層與觸控基準

**What to build:** 在手機瀏覽器打開門市員工網站時，頂欄、側欄抽屜與主要操作按鈕可穩定單手使用：觸控熱區足夠、字級／間距有一致基準、選單開關不誤觸，且不與系統安全區（瀏海／底部手勢列）衝突。此票只交付「殼層可用」，不改各業務頁清單版型。

**Constraint:** 電腦／寬螢幕（>900px）繼續使用原本常駐側欄 UI；本票所有視覺與抽屜行為僅在手機網頁寬度生效。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 手機寬度下可開關主選單，開啟時背景不可捲動，點遮罩可關閉
- [x] 頂欄關鍵操作（選單、信箱、登出等）觸控目標足夠、不易誤觸
- [x] 定義並套用手機斷點／觸控／字級基準（延續現有約 900px 抽屜行為，必要時補充更小寬度規則）
- [x] 桌面版外觀與操作不因本票明顯退化
