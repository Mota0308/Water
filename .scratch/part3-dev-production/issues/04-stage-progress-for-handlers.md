# 04 — 項目詳情與經手人階段推進

**What to build:** 開啟項目後可看概覽與階段流程。被指派為該階段經手人的 personal 可更新自己負責且已輪到的階段狀態（MVP 至少含：進行中、待確認、需要修改、已完成、直接下一階段／不適用等與示範相容的必要子集），可填簡短說明。非經手人的 personal 與所有 manager 對階段操作唯讀。留言板與多版本附件不在本票。
