# 02 — 生產項目資料模型與建立

**What to build:** 系統管理員可建立「開發及生產」或「補貨」項目：產品編號、名稱、分類、說明、整體期限，並為各階段指派經手人。開發固定 7 階段、補貨固定 6 階段（與示範一致）。經手人從啟用中的 personal 賬號選擇，列表顯示姓名與部門（無部門顯示 —）。資料持久化至 Mongo。

**Blocked by:** 01 — 左側大模組殼層

**Status:** done

- [x] system_admin 可建立開發項目（7 階）與補貨項目（6 階）
- [x] 建立時可為各階段指定經手人（active personal）
- [x] personal／manager 無法建立項目
- [x] 新建項目可在資料庫讀回，階段初始狀態合理（例如首階待處理、其餘未開始，或與示範等價規則）
- [x] Application API 對建立成功／無權限有測試覆蓋
