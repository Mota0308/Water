# 03 — 建立調貨單（待確認，含權限）

**What to build:** 管理層／系統管理員可新增調貨單：選擇調出門市、調入門市（不可相同、僅四間港店）、動態加入多個商品，每個商品可填多個尺碼數量；可填備註。提交前驗證數量非負、不超過調出門市該尺碼現庫、至少一項有效數量。建立成功後狀態為「待確認」，出現在調貨管理列表頂部，並可依狀態／門市／日期篩選。個人賬號不可建立調貨單。

**Blocked by:** 01 — 貨品調動模組殼＋庫存查詢（含權限）; 02 — 商品主檔新增／編輯（含權限）

**Status:** ready-for-agent

- [ ] manager／system_admin 可建立調貨單並持久化至 Mongo
- [ ] 調出≠調入；數量非負且不超調出店該尺碼庫存；至少一項商品尺碼數量
- [ ] 新建單狀態為「待確認」，列表可篩選並顯示於頂部
- [ ] personal 不可建立調貨單
- [ ] 建立當下不扣減庫存（待出貨確認才扣）
