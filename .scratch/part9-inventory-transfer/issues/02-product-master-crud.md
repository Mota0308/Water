# 02 — 商品主檔新增／編輯（含權限）

**What to build:** 在貨品調動模組提供「商品管理」：列表顯示商品編號、名稱、類別、顏色、可用尺碼、安全存量（每尺碼）。管理層／系統管理員可新增與編輯商品；個人賬號僅可查看列表、不可新增／編輯。新商品建立後，四店各尺碼庫存可從 0 起算（或依種子規則初始化），並反映於庫存查詢。

**Blocked by:** 01 — 貨品調動模組殼＋庫存查詢（含權限）

**Status:** ready-for-agent

- [ ] 商品列表可見編號、名稱、類別、顏色、尺碼、安全存量
- [ ] manager／system_admin 可新增商品並寫入 Mongo
- [ ] manager／system_admin 可編輯名稱／類別／顏色／尺碼／安全存量
- [ ] personal 不可新增或編輯商品
- [ ] 商品變更後庫存查詢與安全存量預警使用最新主檔
