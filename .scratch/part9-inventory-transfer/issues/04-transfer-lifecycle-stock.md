# 04 — 調貨狀態流＋庫存異動（含權限）

**What to build:** 管理層／系統管理員可對調貨單執行完整生命週期：「待確認」可確認出貨（扣減調出門市對應尺碼庫存，狀態變「已出貨」）或拒絕（填原因，庫存不變）；「已出貨」可確認收貨（增加調入門市對應尺碼庫存，狀態變「已完成」；可核對／調整實際出貨數量若產品需要）。提供調貨單詳情頁：基本資訊、商品×尺碼明細、狀態時間軸（建立→出貨／拒絕→完成）。個人賬號不可執行出貨／拒絕／收貨。庫存查詢數字隨狀態即時更新。

**Blocked by:** 03 — 建立調貨單（待確認，含權限）

**Status:** ready-for-agent

- [ ] 待確認→出貨：調出店庫存按尺碼扣減；狀態為已出貨
- [ ] 待確認→拒絕：需原因；庫存不變；狀態為已拒絕
- [ ] 已出貨→收貨完成：調入店庫存按尺碼增加；狀態為已完成
- [ ] 詳情頁可見單據資訊、尺碼明細與狀態時間軸
- [ ] personal 不可出貨／拒絕／收貨；manager／system_admin 可以
- [ ] 異動後庫存查詢與 Mongo 資料一致
