# Part 5 — 開發／補貨功能對齊 HTML（決策摘要）

來源：`開發及生產部.html` + grilling（2026-08-03）— 使用者已確認

## 目標

- **功能對齊** HTML 示範（非畫面復刻）
- UI 維持現有深藍殼層／左側模組導覽
- 分批交付：A → B → C → D

## 權限（沿用 Part 3）

- `system_admin`：建立／編輯／暫停／取消、改經手人、確認階段、移除留言、匯出
- `manager`：可看全部；不可上述寫入／管理操作
- `personal`：經手人；推進自己的當前階段；留言／上傳（於對應票定義）

## 批次範圍

### A — 項目生命週期（最小真功能）
- 編輯項目資料（編號、名稱、分類、說明、期限等）
- 暫停、取消（需原因／記錄）
- 不做封存

### B — 留言
- 項目留言、回覆
- `@姓名` 高亮顯示
- 「被提及」列表（首頁或我的工作區）
- admin 可移除留言（軟刪，管理層仍可查）
- 不做推播／電郵

### C — 檔案多版本
- 同文件多名版本；標示最新
- 儲存：**本機 uploads 目錄 + DB 中繼資料**
- 介面預留可換成遠端／NAS（日後 Railway + NAS）
- 不做立刻接 NAS

### D — 匯出
- CSV 匯出項目／階段摘要
- 不做 Excel／PDF

## 明確不做（本輪共識）

- 像素級復刻 HTML
- 完整封存流程
- Excel／PDF 匯出
- 推播／電郵通知
- 立刻接 NAS 儲存
