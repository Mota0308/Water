# 03 — C：檔案多版本（本機 uploads）

**What to build:** 項目可上傳檔案；同一邏輯文件可有多版本，舊版保留並標示最新。DB 存中繼資料（名稱、版本、上傳者、時間、路徑）；檔案本體存本機 `uploads/`（或等價目錄）。儲存實作抽象為可替換埠，以便日後改接 NAS／遠端。下載最新／指定版本。manager 可看／下載；上傳權限：system_admin 與經手相關 personal（至少 admin＋該項目階段經手人可上傳）。

**Blocked by:** None（建議在 B 之後，與留言同頁分區）
