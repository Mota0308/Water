# 05 — 跨單位當日進度唯讀

**What to build:** 個人賬號可進入各單位進度，查看五個單位的當日總數、已完成、未完成、逾期與完成百分比，並點進其他單位查看當日工作名稱、狀態、期限、完成時間、最後更新與完成者姓名。頁面為唯讀：無剔選／編輯／取消等操作，不顯示詳細說明、備註與附件，頂部有明確唯讀提示。不可查看過往日期。

**Blocked by:** 03 — 突發工作：建立 → 今日清單 → 剔選／取消

**Status:** ready-for-agent

- [ ] 個人可查看五個單位的當日進度摘要（總數／完成／未完成／逾期／百分比）
- [ ] 點進其他單位可看到當日工作名稱、狀態、完成時間、最後更新、完成者姓名
- [ ] 其他單位檢視不暴露詳細操作說明、備註、附件
- [ ] 其他單位檢視不出現任何修改類操作控件／API 亦拒絕修改
- [ ] 頁面或回應中有「只供查看，不可修改」之類提示
- [ ] 個人跨單位查看僅限當日，不能翻歷史
- [ ] 可見性與拒絕寫入有 Application API 測試覆蓋
