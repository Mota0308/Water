# 08 — 重新開啟、編輯留痕、停用／取消與權限閘門

**What to build:** 一般管理層與系統管理員可重新開啟已完成工作（需填原因）、編輯工作並保留修改前後內容與操作者時間、停用恆常或取消突發工作。系統不提供永久刪除工作或稽核記錄。個人無法使用這些管理能力。一般管理層與系統管理員的既定能力邊界（賬號治理僅系統管理員；工作管理兩者皆可）在 API 與介面一致生效。

**Blocked by:** 02 — 賬號治理與固定單位落地; 03 — 突發工作：建立 → 今日清單 → 剔選／取消

**Status:** ready-for-agent

- [ ] 管理層可重新開啟已完成工作並記入原因、操作者與時間；原完成紀錄仍可追溯
- [ ] 編輯已有完成紀錄的工作時，保留歷史完成資料並記錄修改前後內容
- [ ] 恆常工作可停用、突發工作可取消；不提供永久刪除
- [ ] 個人賬號無法重新開啟／編輯／停用／取消
- [ ] 一般管理層仍無法執行賬號治理；系統管理員可
- [ ] 權限閘門與留痕行為有 Application API 測試覆蓋
