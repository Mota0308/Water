# 02 — 賬號治理與固定單位落地

**What to build:** 系統管理員可以建立與治理賬號（個人／一般管理層／系統管理員），為個人賬號設定五個單位之一為固定所屬單位。個人登入後直接進入所屬單位頁面且不能自選門市；可自行改密；系統管理員可重設密碼、暫停／啟用、立即生效的調職（舊單位未完成工作不隨人走）並留下單位變更紀錄。一般管理層無法執行賬號治理。

**Blocked by:** 01 — 專案骨架與登入登出

**Status:** ready-for-agent

- [ ] 系統管理員可建立個人賬號（姓名、登入名稱、初始密碼、固定單位，職位／部門選填）
- [ ] 固定單位僅可為觀塘、荔枝角、灣仔、屯門、國內倉
- [ ] 個人登入後自動進入固定所屬單位範圍，無法自行更改單位
- [ ] 個人可在驗證舊密碼後自行修改密碼
- [ ] 系統管理員可重設密碼、暫停與重新啟用賬號；停用賬號無法登入
- [ ] 更改固定單位立即生效，並記錄原單位／新單位／操作者／時間（原因欄位若介面有則一併記錄）
- [ ] 調職不轉移舊單位未完成工作實例
- [ ] 一般管理層呼叫賬號治理能力會被拒絕
- [ ] 上述授權與調職行為有 Application API 測試覆蓋
