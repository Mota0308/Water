# 09 — 歷史篩選、人員統計與 CSV／Excel 匯出

**What to build:** 一般管理層與系統管理員可按日期、單位、員工、類型、狀態、優先程度、是否逾期等條件查閱歷史工作與完成紀錄；可查看人員完成數量與逾期統計（不做公開單位排名）。可將篩選結果手動匯出為 CSV／Excel。個人賬號無法使用這些管理查閱／匯出能力。

**Blocked by:** 03 — 突發工作：建立 → 今日清單 → 剔選／取消; 08 — 重新開啟、編輯留痕、停用／取消與權限閘門

**Status:** ready-for-agent

- [x] 管理層可依多條件篩選歷史工作與完成紀錄
- [x] 管理層可查看人員完成量與逾期統計（可篩日期／單位）
- [x] 不提供面向個人賬號的公開單位進度排名
- [x] 管理層可手動匯出 CSV／Excel（內容對應目前篩選）
- [x] 個人賬號無法匯出或查看管理層人員統計
- [x] 查詢授權與匯出行為有 Application API 測試覆蓋
