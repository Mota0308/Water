# 06 — 每日結算預留與國內倉排除

**What to build:** 支援「每日結算」工作類型：建立時僅能分配給觀塘／荔枝角／灣仔／屯門，國內倉不可被選、不會產生實例。門市今日清單可看到該工作，但狀態為預留／未連接日結模組，個人與管理層皆不可手動剔選完成或取消完成。國內倉完成百分比與未完成／逾期計算不包含每日結算工作。

**Blocked by:** 04 — 恆常工作產生與同一實例跨日延續

**Status:** ready-for-agent

- [ ] 可建立標記為每日結算的工作；適用單位自動限於四間香港門市
- [ ] 國內倉不會被分配、不會產生每日結算實例
- [ ] 門市清單可顯示每日結算工作，但拒絕任何手動完成／取消完成
- [ ] 狀態呈現為預留／等待第二部分連接（或同等語意）
- [ ] 國內倉進度計算不因缺少每日結算而顯示未完成或被計入分母
- [ ] 上述規則有 Application API 測試覆蓋
