# 03 — 突發工作：建立 → 今日清單 → 剔選／取消

**What to build:** 一般管理層可為一個或多個單位建立突發工作；該單位個人賬號在今日工作看到清單與進度摘要，可確認後剔選完成（單位任務制：任一同事可完成、記完成者、完成即生效）。完成者可無時限、不需原因地取消自己的剔選；不可取消他人、不可操作其他單位。所有完成／取消寫入稽核。

**Blocked by:** 02 — 賬號治理與固定單位落地

**Status:** ready-for-agent

- [ ] 一般管理層可新增突發工作（名稱、內容、適用單位、開始／期限、優先程度等基本欄位）
- [ ] 個人今日工作顯示所屬單位突發工作與完成進度計數／百分比
- [ ] 所屬單位任一個人可剔選完成未完成工作；完成後他人不可再剔選
- [ ] 完成記錄包含完成者姓名、日期時間，且無需管理層再確認
- [ ] 完成者可取消自己的剔選（無時限、不需原因）；不可取消他人
- [ ] 個人無法剔選或其他方式修改其他單位工作
- [ ] 完成與取消皆留下可查稽核（人員、時間、狀態前後）
- [ ] 上述行為有 Application API 測試覆蓋
