# 04 — 恆常工作產生與同一實例跨日延續

**What to build:** 一般管理層可建立恆常工作範本（週期、適用單位、期限、優先程度、排序等）。系統依設定為各適用單位產生工作實例；若實例未完成，以同一筆延續到後續日子並可標示逾期，在完成／取消／範本停用前不為同一範本＋單位再產生第二筆。個人今日清單可同時看到恆常與突發工作。

**Blocked by:** 03 — 突發工作：建立 → 今日清單 → 剔選／取消

**Status:** ready-for-agent

- [ ] 一般管理層可新增／編輯恆常工作範本並設定重複週期與適用單位
- [ ] 系統可依設定為適用單位產生當日（或應出現日）的恆常工作實例
- [ ] 未完成實例跨日以同一筆延續，並可標示為逾期
- [ ] 延續期間不會為同一範本＋同一單位重複產生第二筆未完成實例
- [ ] 實例完成後，後續符合週期的日子可再產生新實例
- [ ] 個人今日工作可區分並完成恆常工作（沿用單位任務剔選規則）
- [ ] 產生與延續規則有 Application API 測試覆蓋
