# 07 — 附件與完成備註規則

**What to build:** 建立／編輯工作時可設定附件為無需／選填／必填（圖片與 PDF），以及完成備註為選填或必填。個人在所屬單位完成工作時，若違反必填規則則無法完成；符合規則時可上載並完成。所屬單位同事與管理層可查看已上載附件；跨單位摘要仍不可見附件內容。

**Blocked by:** 03 — 突發工作：建立 → 今日清單 → 剔選／取消

**Status:** ready-for-agent

- [ ] 工作可設定附件需求：無需／選填／必填，並限制圖片與 PDF
- [ ] 工作可設定完成備註：選填或必填（預設選填）
- [ ] 必填附件或必填備註未滿足時，完成操作被拒絕
- [ ] 滿足規則後可成功完成，且附件可被所屬單位／管理層查看
- [ ] 跨單位唯讀檢視仍不暴露附件
- [ ] 規則與授權有 Application API 測試覆蓋
